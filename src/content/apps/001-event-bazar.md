## About Event Bazar

Event Bazar is a community-powered Android app for discovering upcoming cybersecurity events and sharing new opportunities with other members.

## Features

- Browse curated and upcoming CTFs, workshops, hackathons, and career events
- View event dates, start times, formats, difficulty levels, and organizers
- Create and publish events for the community
- Build a member profile and manage published event posts
- Search for members and start conversations
- Save events and receive alerts
